# 📊 Sales Data Analysis Dashboard

## 📌 Overview

This project focuses on analyzing sales data using Python and visualizing insights through an interactive Power BI dashboard. The goal is to uncover trends, evaluate regional performance, and identify top-performing products.

---

## 🚀 Features

* Data cleaning and preprocessing using Python
* Exploratory Data Analysis (EDA)
* Interactive Power BI dashboard
* KPI metrics and dynamic filtering

---

## 🛠️ Technologies Used

* Python (Pandas, Matplotlib, Seaborn)
* Power BI
* SQL

---

## 📊 Dashboard Components

### 🔹 KPI Cards

* Total Sales
* Total Profit
* Total Orders

### 🔹 Visualizations

* Sales by Category
* Profit by Region
* Monthly Sales Trend
* Top 10 Products by Sales

### 🔹 Filters

* Region
* Category
* Year

---

## 📈 Key Insights

* Technology and Furniture are top-performing categories
* Regional differences exist in profit margins
* Sales trends vary across months
* Top 10 products contribute major revenue

---

## 📂 Dataset

* Global Superstore Dataset (50K+ records)

---

## ▶️ How to Run

1. Load dataset in Python
2. Perform data cleaning and EDA
3. Export cleaned data as CSV
4. Import into Power BI
5. Build dashboard
